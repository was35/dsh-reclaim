# Triage Labels

技能用五个固定的分类角色说话。本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| mattpocock/skills 里的标签 | 本仓库的标签 | 含义 |
| -------------------------- | ------------ | ---- |
| `needs-triage`             | `needs-triage`      | 维护者需要评估这个 issue |
| `needs-info`               | `needs-info`        | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`   | 已完整说明，可以交给 AFK agent |
| `ready-for-human`          | `ready-for-human`   | 需要人来实现 |
| `wontfix`                  | `wontfix`           | 不会处理 |

当某个技能提到一个角色（例如“打上 AFK-ready 那个分类标签”），就用这张表里对应的标签字符串。

右列目前与仓库里的标签一字不差（保留默认五角色）。将来若改用别的词汇，改右列即可。
